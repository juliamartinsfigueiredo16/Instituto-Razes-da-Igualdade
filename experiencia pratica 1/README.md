# Instituto Raízes da Igualdade

Projeto de site institucional para uma ONG fictícia voltada à educação antirracista. O site apresenta a organização, suas iniciativas sociais e um formulário para pessoas interessadas em contribuir como voluntárias, doadoras ou parceiras.

## Objetivo

Demonstrar a aplicação de HTML5 semântico, acessibilidade e validações nativas em um projeto web de organização do terceiro setor.

## Páginas

- `index.html`: apresentação institucional, missão, visão, valores e contato.
- `projetos.html`: projetos sociais e respectivos impactos.
- `cadastro.html`: formulário de interesse para voluntariado, doação e parceria.

## Recursos utilizados

- Estrutura semântica com `header`, `nav`, `main`, `section`, `article` e `footer`.
- Navegação consistente entre todas as páginas.
- Imagem com texto alternativo (`alt`) para leitores de tela.
- Formulário organizado com `fieldset` e `legend`.
- Validações HTML5 para campos obrigatórios, e-mail, CPF, telefone, CEP e data de nascimento.
- Máscaras de formato com o atributo `pattern` para CPF, telefone e CEP.

## Como visualizar

Abra o arquivo `index.html` em qualquer navegador moderno. A partir dele, use o menu para navegar entre as páginas.

## Acessibilidade

O projeto utiliza textos alternativos nas imagens, rótulos vinculados aos campos do formulário e agrupamentos semânticos para tornar a navegação mais clara para pessoas que utilizam tecnologias assistivas.
