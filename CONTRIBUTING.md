# Guia de contribuição

## Fluxo GitFlow

1. Crie uma branch `feature/nome-da-funcionalidade` a partir de `develop`.
2. Faça commits semânticos, como `feat:`, `fix:`, `docs:` ou `refactor:`.
3. Teste a alteração em navegadores e com navegação por teclado.
4. Abra uma Pull Request para `develop`, descrevendo objetivo, testes e issue relacionada.
5. Após revisão, integre a alteração. Releases aprovadas seguem para `main`.

## Issues

Use o modelo de bug para falhas e o modelo de acessibilidade para melhorias relacionadas às WCAG.
