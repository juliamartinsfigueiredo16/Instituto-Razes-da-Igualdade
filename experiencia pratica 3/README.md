# Experiência Prática III

Estrutura inicial da SPA do Instituto Raízes da Igualdade.

## Build de produção

Execute `./build.ps1` dentro desta pasta. O script gera `dist/` com HTML, CSS e JavaScript reduzidos, preservando os arquivos originais para manutenção. A versão pronta para publicação começa em `dist/index.html`.

```text
experiencia pratica 3/
├── html/       # páginas e marcação HTML
├── css/        # estilos da aplicação
├── imagens/    # imagens e demais recursos visuais
└── js/         # lógica JavaScript modular
```
